# app/app_e_task 接口说明

## 模块职责

`app/app_e_task` 负责 2025 年全国大学生电子设计竞赛 E 题前三项基础要求的任务流程编排。

当前只覆盖基础要求：

- 要求 1：小车自主循迹逆时针运行 `N=1..5` 圈，限时 20 秒，瞄准模块不参与控制。
- 要求 2：小车任意位姿放置，瞄准模块在 2 秒内瞄准靶心。
- 要求 3：小车位于指定位置，瞄准方向任意，瞄准模块在 4 秒内瞄准靶心。

该模块负责：

- 调用 `core/line_tracking` 执行巡线控制。
- 调用 `core/gimbal_tracking` 执行靶心视觉跟踪。
- 依据 `middleware/line_follow` 的线状态辅助完成圈数计数。
- 通过 `middleware/ui` 显示任务运行状态。

该模块不负责：

- 维护 PID 参数本身。
- 解析 CanMV 协议。
- 管理具体电机 GPIO 或 PWM。
- 维护 Keil、CCS 工程文件。

## 公开接口

### `void AppE_RunLineFollow(uint8_t lap_count)`

执行基础要求 1。`lap_count` 表示目标圈数，内部会限制到 `1..5`。

当前圈数计数逻辑：

- 每圈按 4 条边线估算。
- 使用 `LineFollow_IsHalfDetected()` 判定边线/半线。
- 使用 `Chassis_GetDistance()` 增加最小距离门限，减少同一条线重复计数。

该逻辑需要上板后结合场地、车速和灰度阈值继续校准。

### `void AppE_RunAimCenter2s(void)`

执行基础要求 2。内部调用云台视觉跟踪，在 2 秒窗口内持续把激光点收敛到靶心。

### `void AppE_RunAimCenter4s(void)`

执行基础要求 3。内部调用云台视觉跟踪，在 4 秒窗口内持续把激光点收敛到靶心。

## 关键约束

- 任务运行中长按按键可中止并返回菜单。
- 要求 1 启动时会停止云台输出，避免瞄准模块参与循迹任务。
- 要求 2、3 启动时会先刹停底盘，只执行云台瞄准。
- 巡线过程中检测到丢线会立即刹车并进入提示页。
- 瞄准任务结束后会调用 `GimbalTracking_Stop()` 停止云台输出。
