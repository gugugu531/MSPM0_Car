# app/app_e_task 接口说明

## 模块职责

`app/app_e_task` 负责 2025 年全国大学生电子设计竞赛 E 题前三项基础要求的任务流程编排。

当前只覆盖基础要求：

- 要求 1：小车自主循迹逆时针运行 `N=1..5` 圈，限时 20 秒，瞄准模块不参与控制。
- 要求 2：小车任意位姿放置，瞄准模块在 2 秒内瞄准靶心。
- 要求 3：小车位于指定位置，启动后云台正方向扫描寻找矩形；扫描中一旦识别到有效矩形即停止扫描，并跟踪矩形中心。

该模块负责：

- 调用 `core/motion` 执行底盘运动原语；E1 中使用 `MOTION_MODE_LINE_FOLLOW` 间接执行巡线控制。
- 调用 `core/gimbal_tracking` 执行靶心视觉跟踪。
- 依据 `middleware/line_follow` 的线状态辅助完成圈数计数。
- 通过 `middleware/ui` 显示任务运行状态。

该模块不负责：

- 维护 PID 参数本身。
- 解析 CanMV 协议。
- 管理具体电机 GPIO 或 PWM。
- 维护 Keil、CCS 工程文件。

## 公开接口

### `void AppE_RunLineFollow(uint8_t lap_count)`

执行基础要求 1。`lap_count` 表示目标圈数，内部会限制到 `1..5`。

当前圈数计数逻辑：

- 先构造 `Motion_CommandLineFollow()`，循环中周期调用 `Motion_Apply()` 执行一次巡线运动输出。
- 普通循线状态下使用 0 到 7 的全部 8 路灰度传感器。直角弯入口改为 8 路全部未检测到轨道，且连续确认 2 次才正式进入转弯流程。
- 直角弯由 E1 任务状态机完成：确认转角后先主动刹车约 `120ms`，压低入弯惯性，然后复用 `Corner test` 的转弯动作；当前左转为左轮约 `-25%`、右轮约 `+25%`，通过原地差速转向提高直角弯响应。
- 转弯不设置固定持续时间；转弯过程中中心 3 或 4 连续 3 次重新检测到线后，先刹车，再恢复普通循线。
- 直角弯进入确认计数、当前转弯方向和退出确认计数在 E1 主循环中显式维护，便于后续上板调参时直接观察和修改。
- 每圈按 4 条边线估算。
- 使用 `LineFollow_IsHalfDetected()` 判定边线/半线。
- 使用 `Chassis_GetDistance()` 增加最小距离门限，减少同一条线重复计数。
- 普通循线状态下，`Line lost` 使用同一有效通道掩码判断；只要 0 到 7 中任意一路检测到线，就不认为丢线。
- 每次识别到直角弯并进入圆弧转弯时会累加转弯次数；若后续进入 `Line lost`，提示页会显示该次数，便于定位丢线发生在第几次转弯之后。
- 任务完成、丢线、中止和超时仍由 E1 自己判断；`core/motion` 不负责这些条件。

该逻辑需要上板后结合场地、车速和灰度阈值继续校准。

### `void AppE_RunCornerBrakeTest(void)`

执行拐角识别左转测试。进入后先执行普通循线，使用与 E1 相同的空线拐角确认逻辑；当 8 路灰度全部未检测到轨道并连续确认后，先主动刹车约 `120ms`，随后按固定动作执行低速左转。

当前测试动作与 E1 正式转弯一致：左轮 `-25%`、右轮 `+25%`，转弯过程中保留中心线检测；中心 3 或 4 连续确认后立即主动刹车，不设置固定时间兜底停止。该设置用于增大差速，提高左转响应，同时观察中心线停止条件是否可靠。

该入口只用于调试拐角识别触发时机和左转动作参数，不计圈，也不自动恢复循线。若中心线一直未被检测到，测试会持续左转，需长按按键人工中止；后续需要结合实车角度继续校准中心线连续确认次数和左右轮占空比。

### `void AppE_RunAimCenter2s(void)`

执行基础要求 2。内部调用云台视觉跟踪，持续把 K230 回传的目标中心收敛到图像中心。当前 K230 端已对倒装摄像头坐标做中心对称修正，并以图像中心作为当前实际点位发送，单片机侧不再重复翻转坐标。

当前 E2 不再按固定 2 秒窗口自动结束；只要仍能收到可用于跟踪的有效 K230 目标数据，云台会持续调整。若长时间没有有效目标数据，视觉跟踪层会停止云台输出并返回；用户也可以长按按键中止。

### `void AppE_RunAimCenter4s(void)`

执行基础要求 3。进入任务后先等待启动按键释放，避免菜单长按事件残留导致任务立即退出。随后让云台 yaw 以约 `60 deg/s` 正方向慢速扫描，扫描角度最多一圈，并额外设置约 `8s` 的扫描超时保护；扫描过程中只查询 `CANMV_TARGET_RECT` 是否有效，不触发视觉跟踪超时停机。识别到有效矩形后立即停止扫描，不再继续转满一圈。

扫描成功后进入矩形中心跟踪，在 4 秒窗口内调用 `GimbalTracking_UpdateRectCenter()` 持续把矩形中心收敛到图像中心。若跟踪阶段长时间没有有效 K230 目标数据，视觉跟踪层会停止云台输出并提前退出。

## 关键约束

- 任务运行中长按按键可中止并返回菜单。
- 要求 1 启动时会停止云台输出，避免瞄准模块参与循迹任务。
- 要求 2、3 启动时会先刹停底盘，只执行云台动作。
- 巡线过程中持续丢线超过约 1 秒后会刹车并进入提示页。
- 瞄准或矩形跟踪任务结束后会调用 `GimbalTracking_Stop()` 停止云台输出。
