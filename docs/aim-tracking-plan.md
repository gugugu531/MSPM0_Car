# 自瞄追踪开发路线图（模型前馈 + 视觉慢校正）

> 本文档是 2025E 追踪瞄准子系统的开发主计划，源自"按 BSP 硬件能力反推的最优设计"。
> 每一步严格按工作流推进，未经审阅/验收不进入下一步。

## 工作流（每一步都遵守）

1. **开发计划**：给出该步的目标、改动文件、接口草案、依赖 → 提交审阅。
2. **审阅修改**：按反馈修订计划。
3. **实现**：按定稿计划编码。
4. **验收规范**：给出可验证的验收标准（单测/编译/上板现象）→ 提交验收。
5. **验收通过**：更新本文档状态，进入下一步。

## 设计总纲（一句话）

底盘传感器答"车在哪"，赛题几何答"靶在哪"，两者相减即云台绝对角（连续、零滞后前馈）；
K230 视觉只用低增益积分修最后约 0.8° 残差。加速度计不测速，陀螺仪补单轮里程。

### 由 BSP 能力钉死的关键决策
- F32C 有**绝对角反馈**但**总线慢** → 位置模式喂绝对角（开环式精确定位），反馈仅低频校验，不做高频视觉伺服。
- IMU 在**底盘**非云台 → 用底盘 IMU 估车位姿做前馈，学不了"云台陀螺增稳"。
- 单 QEI → 用陀螺 `v_center = v_wheel + ωz·y_w` 重构车心速度，不加硬件。
- 靶固定 + 几何已知 + 位姿可观测 → 云台角是纯几何函数，天然满足"连续发光"硬约束。

### 坐标系
世界系：原点 = AB 边中点，+X 沿 A→B，+Y 指靶外侧，+Z 向上。
车位姿 `(x, y, ψ)`，ψ = 车体前向相对世界 +X 的夹角（IMU 融合航向）。

### 精度预算（远端 R≈1.5m → 需 0.8°）
| 误差源 | 传导 | 预算 | 对策 |
|---|---|---|---|
| IMU 航向 δψ | 1:1 | <0.8° | 融合航向 + 视觉 bias 收尾 |
| 横向位置 δ | δ/R | <1.5cm | 角点 snap + 车心重构 + bias |
| 距离 | pitch 不敏感 | 宽松 | 里程标定 |
| 机械/靶心标定 | 系统性偏 | — | 实机标 + bias |

## 分步路线图

### Phase A — 纯计算内核（主机可单测，不碰硬件，放 `core/`）

- `[x]` **S1 几何瞄准解算器**：车位姿 + 靶心（2D 世界 + 标量 Δz）→ 云台 yaw/pitch/range；发挥(3) 圆点解算。纯函数。竖直坍缩为 `height_diff_m`，位姿与靶心 2D 化。主机单测 27/27，固件 0 error。**已验收**。
- `[x]` **S2 位姿估计器**：单轮里程 + 陀螺重构车心速度 → 航位推算；角点 snap 重锚 x/y 与弧长；圈进度/相位。纯函数。核对现有实现符合设计，加 `Localization_UpdateFromWheel` 组合入口 + `last_center_delta_m` 字段，补 34 处断言主机单测。固件 0 error。**已验收**。
- `[x]` **S3 融合层**：新建 `core/aim_fusion`。静态角前馈 + 速率前馈 `ẏaw=v·sinΔβ/Rh−ω`（+pitch_rate）+ 视觉慢校正 bias（自 aim_solver 迁入，丢失冻结、限幅）→ `AimFusion_Combine` 最终指令。纯函数。aim_solver 回归纯几何。主机单测 21/21，固件 0 error。**已验收**。

### Phase B — 硬件执行与接入（放 `middleware/`、`app/`）

- `[ ]` **S4 云台服务**：F32C 位置模式 SetAngle（绝对角）+ 软件限位 + 加速度整定 + 低频反馈校验；对上层屏蔽电机细节。
- `[V]` **S5 传感器接入 + 位姿实机验证**：传感器→位姿→云台链路已由 auto_aim 具备；本步把 S3 速率前馈以 lead-time 接入 `AutoAim_Update`（默认 0=纯静态前馈），Geo feedforward 测试台提速到 200Hz + 屏显 heading/gyro/rate。软件侧固件 0 error、主机单测不回归；**yaw 稳定性待你上板实测**。

### Phase C — 任务打通

- `[ ]` **S6 自瞄协调器 + 基本(3)**：S2+S3+S4 串起来，已知位姿静态前馈一步到位 + 视觉 bias 修到 D≤2cm。
- `[ ]` **S7 K230 视觉管线**：cv_lite + SEARCH/LOCK/COAST 状态机 + 几何/尺寸/时间三层筛选 + ROI + 角度误差输出；**激光偏移先置零（同轴假设）**。目标 headless 60–80fps。
- `[ ]` **S8 发挥(1)(2) 连续打靶**：运动中前馈连续瞄 + 视觉 bias + 打点/超时兜底状态机。
- `[ ]` **S9 发挥(3) 边跑边画圆**：`SolveCircle` + 里程弧长参数化相位（车 1 圈 = 画 1 圈天然同步）。
- `[ ]` **S10 激光-相机偏移真值标定**：用光点标定脚本测 b/α，填参数消同轴假设残差。

### 独立项（可穿插）

- `[ ]` **S11 基本(2) 纯视觉找靶**：位姿未知场景，矩形中心视觉闭环（唯一以视觉为主的题）。
