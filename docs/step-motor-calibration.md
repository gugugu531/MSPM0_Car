# 摆杆步进电机标定手册

全部标定都在 `Main Menu -> Device Check -> Step Motor` 页完成，配合 Debug_Ex（UART1，
115200）的 `[SM]` 遥测。参数改完后重新编译烧录。

页面按键：

| 键 | 动作 |
|---|---|
| UP / DOWN | 持续正转 / 反转（`SM_RUN_SPEED_DEG_S`，默认 30 deg/s） |
| ENTER 短按 | 停脉冲 + 编码器与开环估计双清零（**仍通电**） |
| ENTER 长按 | 切换驱动器使能，断电后轴可手动转动 |
| BACK | 退出（只停脉冲，不断电） |

`[SM]` 一行的字段：`cmd` 指令速度、`f` 实际步进频率、`load` 定时器装载值、
`est` 开环估计角、`qei` 编码器换算角、`cnt` 编码器累计计数、`raw` QEI 原始 16 位值、
`en` 使能状态、`dir` DIR 电平。

## 1. 定时器时钟 —— 核对，不是测量

驱动用 `period = CLK / f` 算装载值，这个数错了**所有**转速都按同一比例偏。

打开 `board/sys_config/ti_msp_dl_config.h`，找 `SMotor_INST_CLK_FREQ`，确认等于
`62500`。当前 SysConfig 是 32 MHz ÷ (clockDivider 8 × clockPrescale 64) = 62500 Hz。

只要没动 SysConfig 的分频，这一项跳过。**改过分频就必须同步 `step_motor.h`**，编译器不会
报错，只会静默变速。

---

## 2. 细分数 `MICROSTEP`

先读驱动板拨码开关的细分表（通常印在板上），把值填进去。然后实测复核：

1. 在电机轴上贴个标记，ENTER 长按断电，ENTER 短按清零，再长按恢复使能。
2. 按 UP 让它转，用秒表卡 **12 秒**（30 deg/s × 12 s = 360°，正好一圈）。
3. 松开观察标记：**多转了就是 `MICROSTEP` 填小了，少转了就是填大了**。

修正式（`n` = 实际转过的圈数）：

```
MICROSTEP_正确 = MICROSTEP_当前 / n
```

例：填 32、12 秒转了 2 圈 → 实际是 16 细分，改成 `16.0f`。

> 转速是软件按 `f = (speed / 1.8) × MICROSTEP` 算的，`MICROSTEP` 是唯一的比例因子。
> `est`（开环估计角）用同一个假设算，所以**它永远"自洽"，标不出错来**——必须靠眼睛看实际圈数。

---

## 3. 使能极性 `ENABLE_HIGH`

进 Step Motor 页（此时驱动器应已使能），用手拧电机轴：

- **拧不动**（有明显保持力矩）→ 现值正确。
- **能自由转动** → 极性反了，`STEP_MOTOR_BEAM_ENABLE_HIGH` 改成 `0U`。

顺带用 ENTER 长按验证一遍：切到 `drv OFF` 后应该能拧动，切回 `drv ON` 应该拧不动。两个
状态表现一样，说明 EN 线根本没接通或驱动器 EN 脚悬空默认使能。

---

## 4. 方向极性 `POSITIVE_DIR_HIGH`

约定：**正速度 = 摆杆向你定义的正方向偏**（先在机械上定死哪边是正，比如"抬右侧"）。

按 UP（正速度）观察摆杆倒向哪边：

- 与约定一致 → 现值正确。
- 相反 → `STEP_MOTOR_BEAM_POSITIVE_DIR_HIGH` 从 `1U` 改成 `0U`。

⚠ 这一项和 #6 必须**分开做、按顺序做**：先把电机方向定死，再看编码器跟不跟得上。两个一起
翻会互相抵消，测出来的组合是错的但现象是对的。

---

## 5. 编码器每转计数 `ENCODER_COUNTS_PER_REV`

这是唯一一个**必须实测**、猜不出来的值——`1000.0f` 是按 500 线 × 2 倍频的默认猜测，
没有依据。它错了，`qei` 那一栏的刻度就是错的，闭环也就无从谈起。

1. **ENTER 长按**断电（通电时拧不动轴）。
2. **ENTER 短按**清零 `cnt`。
3. 手动把轴**正好转一整圈**（对准标记，慢慢转，别来回找）。
4. 读 OLED 或 `[SM]` 行里的 `cnt`。

```
STEP_MOTOR_ENCODER_COUNTS_PER_REV = |cnt|
```

转 3~5 圈再除以圈数更准，能摊掉对不准标记的误差。改完重新烧录，再转一圈验证：
`qei` 应该读到接近 `360`。

> MSPM0 的 QEI 2-input 模式对 A/B 各取上升沿，是 **2 倍频**，不是常见的 4 倍频。
> 所以理论值 = 编码器线数 × 2。测出来接近线数×4 的话，说明 SysConfig 的 QEI 模式和
> 这里的注释对不上，得回去查。

## 6. 编码器方向 `ENCODER_INVERT`

#4 和 #5 都定完之后：按 UP（正速度）跑两秒，看 `[SM]` 里的 `est` 和 `cnt`。

- 两者**同号增长** → `STEP_MOTOR_ENCODER_INVERT` 保持 `0U`。
- **符号相反**（`est` 涨、`cnt` 跌）→ 改成 `1U`。

改完再跑一次，`est` 和 `qei` 应该同向、且数值接近。这两条曲线持续劈叉就是丢步，直接进 #7。

---

## 7. 最大步进频率 `MAX_STEP_FREQ_HZ`

`5000` 是抄官方例程的，跟你的电压、负载、摆杆惯量都无关，必须自己压出来。

在 `app_checks.c` 里把 `SM_RUN_SPEED_DEG_S` 临时调大，从 30 往上加（60 → 120 → 180 →
240…），每档跑 3~5 秒，看 `est` 和 `qei`：

- 两者始终贴合 → 这档能跑。
- 开始劈叉、或听到"咔咔"堵转声 → **已经丢步**，退回上一档。

取**能稳定跑的最高转速的 80%** 作为工作上限（留出摆杆动态加速的余量），再换算：

```
MAX_STEP_FREQ_HZ = (安全转速_deg_s / 1.8) × MICROSTEP
```

⚠ 一定要**装上摆杆、带真实负载**测。空载能跑到的频率，挂上摆杆通常要打对折。

## 8. `MAX_SPEED_DEG_S`

不用单独测，由 #7 反推，两者保持一致即可：

```
MAX_SPEED_DEG_S = MAX_STEP_FREQ_HZ × 1.8 / MICROSTEP
```

不一致的后果是限幅在两个地方各切一刀，实际上限取更严的那个——不会出错，但会让调参时
"改了没反应"。

---

## 9. 摆杆减速比 `k`

驱动层的所有角度都是**电机轴角**，不是摆杆角。中间隔着连杆/同步带/减速箱：

```
摆杆角 θ = 电机轴角 / k
```

测法：把摆杆摆到一个明确的机械参考位（比如靠住限位块），ENTER 短按清零，用
`StepMotor_RunFor()` 或按住 UP 转到另一个参考位，记下 `qei`（用编码器实测值，别用 `est`），
再用量角器/手机水平仪量摆杆实际转过的角度。

```
k = qei读数 / 摆杆实测角度
```

同步带直连的话 `k` 就是带轮齿数比；有减速箱要再乘减速比。

## 10. 软限位 `MIN/MAX_POSITION_DEG`

现在是 `±100000`，**等于没有限位**——这是机械没装好时的临时设置，装机后必须改回来，
否则程序跑飞会把摆杆顶到机械死点上。

摆杆的物理行程假设是 `±θ_max`（留 5° 安全余量），则：

```
MAX_POSITION_DEG = (θ_max - 5) × k
MIN_POSITION_DEG = -MAX_POSITION_DEG
```

也可以运行时用 `StepMotor_SetPositionLimit()` 覆盖，不必重编译。

> ⚠ 软限位只作用于**开环估计位置** `est`。丢步之后 `est` 和真实角度就脱节了，限位会连
> 带失效。它防的是指令超程，**不能替代物理限位开关**。

## 标定顺序速查

```
1 核对时钟   →  2 细分（眼看圈数）    →  3 EN 极性（手拧轴）
             →  4 DIR 极性（看摆杆倒向）
             →  5 编码器计数（断电手转一圈读 cnt）
             →  6 编码器方向（est / cnt 同号？）
             →  7 最大频率（带负载压到丢步，退一档）→ 8 换算限速
             →  9 减速比（两参考位间量角）          → 10 换算软限位
```

3 和 4 可以互换，其余不能乱序：#2 错了 #7 全错，#5 错了 #6/#9 全错。

## 常见现象对照

| 现象 | 可能原因 |
|---|---|
| 只嗡嗡响不转 | 驱动板线序错（A+/A-/B+/B- 接反），或 `f` 超出电机启动频率 |
| `est` 涨、`cnt` 不动 | 编码器供电 / A、B 线未接，或 QEI 引脚接错 |
| `est` 与 `cnt` 反号 | `ENCODER_INVERT` 需翻转（#6） |
| `est` 与 `qei` 越跑越远 | 丢步，降 `MAX_STEP_FREQ_HZ`（#7）或加大驱动电流 |
| 转速整体差固定倍数 | `MICROSTEP`（#2）或 `STEP_TIMER_CLK_HZ`（#1）不对 |
| `f=0`、`load=0` | 指令速度落进死区，低于 `MIN_STEP_FREQ_HZ` |
