# 摆杆步进电机标定手册

全部标定在 `Main Menu -> Device Check -> Step Motor` 页完成，配合 Debug_Ex（UART1，
115200）的 `[SM]` 遥测。参数改完后重新编译烧录。

## 页面结构

该页分五个标定模式，**ENTER 长按**循环切换，**BACK** 退出整页。标题栏显示当前模式
（如 `SM 3/5 HAND`）。每个模式只负责一到两项标定，并把该填回 `step_motor.h` 的那个数
**直接算好显示出来**，不用在现场心算。

| 模式 | UP / DOWN | ENTER 短按 | 标定项 |
|---|---|---|---|
| `1/5 RUN` | 持续正转 / 反转 | **暂停**（保留读数） | DIR 极性、编码器方向 |
| `2/5 TURN` | 目标圈数 ±1 | 开始（走满自动停）/ 中止 | 细分数 |
| `3/5 HAND` | 已手转圈数 ±1 | 清零 | 编码器每转计数、EN 极性 |
| `4/5 SWEEP` | 转速档 ± | 启动 / 停止本档 | 最大步进频率 |
| `5/5 SPAN` | **按住**点动正 / 反 | 交替打 A / B 点 | 减速比、软限位 |

切模式会自动停机。进入 `HAND` 自动断电（轴可手转），离开 `HAND` 自动恢复使能；退出
整页时也恢复使能——摆杆有重力负载，断电会自重回落。

`est` 与编码器计数**只在退出整页时清零**（另有 `TURN`/`HAND`/`SWEEP` 起测时按各自需要
清零）。页内暂停一律保留读数——停下来正是为了读它。

`[SM]` 遥测每行的字段：`m` 模式序号、`t` 时间戳、`cmd` 指令速度、`f` 实际步进频率、
`load` 定时器装载值、`est` 开环估计角、`qei` 编码器换算角、`cnt` 编码器累计计数、
`raw` QEI 原始 16 位值、`en` 使能状态、`dir` QEI 方向标志。进入页面时另打一行
`clk / min_f / max_f / ustep / cpr`，便于与驱动器拨码、SysConfig 分频当场对账。

## 需要标定的量

| # | 宏 | 现值 | 用哪个模式 |
|---|---|---|---|
| 1 | `STEP_MOTOR_STEP_TIMER_CLK_HZ` | `62500`（已核对） | 不测量，只核对 |
| 2 | `STEP_MOTOR_MICROSTEP` | `8.0f`（已实测，与拨码一致） | `TURN` |
| 3 | `STEP_MOTOR_BEAM_ENABLE_HIGH` | `1U`（已实测） | `HAND` |
| 4 | `STEP_MOTOR_BEAM_POSITIVE_DIR_HIGH` | `1U`（已实测） | `RUN` |
| 5 | `STEP_MOTOR_ENCODER_COUNTS_PER_REV` | `2000.0f`（已实测） | `HAND` |
| 6 | `STEP_MOTOR_ENCODER_INVERT` | `1U`（已实测） | `RUN` |
| 7 | `STEP_MOTOR_MAX_STEP_FREQ_HZ` | `5000` | `SWEEP` |
| 8 | `STEP_MOTOR_MAX_SPEED_DEG_S` | `240.0f` | 由 #7 换算 |
| 9 | 摆杆减速比 `k` | 上层未定义 | `SPAN` |
| 10 | `STEP_MOTOR_MIN/MAX_POSITION_DEG` | `±100000`（等于不限位） | 由 #9 换算 |

**顺序不能乱**：#2 错了 #7 全错，#5 错了 #6 和 #9 全错。推荐次序：

```
1 核对时钟 → 2 TURN → 3+5 HAND → 4+6 RUN → 7 SWEEP → 8 换算 → 9 SPAN → 10 换算
```

## 1. 定时器时钟 —— 核对，不是测量

驱动用 `period = CLK / f` 算装载值，这个数错了**所有**转速都按同一比例偏。

打开 `board/sys_config/ti_msp_dl_config.h`，确认 `SMotor_INST_CLK_FREQ` 等于 `62500`
（32 MHz ÷ clockDivider 8 ÷ clockPrescale 64）。没动过 SysConfig 分频就跳过。

**改过分频就必须同步 `step_motor.h`**——编译器不会报错，只会静默变速。

> **#2 量的其实是本值与 `MICROSTEP` 的比值。** 推导里两者只以比值出现，任一个错了另一个
> 都会补偿回来，角度刻度照样准——单靠数转过几圈分不出是谁错。判别办法是拿拟合出的
> `MICROSTEP` 去对驱动板拨码开关：**对得上**说明本值没被用来吸收误差，时钟正确；
> **对不上**（比如拟合 8 而拨码 32）说明真实时钟是 `62500 × 32/8 = 250 kHz`，
> 所有频率量的含义都差 4 倍，得回 SysConfig 查分频。
>
> 本机已核对：拟合 8、拨码 8，一致，62500 Hz 正确。

## 2. 细分数 `MICROSTEP` —— `TURN` 模式

先读驱动板拨码开关的细分表填进去，然后实测复核。

0. 先读驱动板拨码开关，记下它标称的细分数——第 4 步之后要拿来对账。
1. 轴上贴个标记，切到 `TURN`（进入即自动清零）。
2. UP/DOWN 设 `N`（默认 1 圈；不确定时设 2，判读更准）。
3. ENTER 开始。驱动按开环走满 `N × 360°` **自动停**，状态显示 `DONE`。
4. 看标记实际转过几圈。

```
MICROSTEP_正确 = MICROSTEP_当前 / 实际圈数 × N
```

实测记录：`N=1`、填的 32、实际转了 4 圈 → 真实细分 `32/4 = 8`，已改成 `8.0f`；
与驱动板拨码读数（8）一致。换驱动板或拨过拨码后必须重测。

> **这一项光看遥测标不出来。** 转速和 `est` 都是用同一个 `MICROSTEP` 算的，永远自洽。
> 必须靠眼睛数实际圈数。

页面上的 `c/N` 栏是 `cnt / N`，即编码器每转计数的交叉验证值——等 #5 做完回来再看，
两者对不上说明 #2 或 #5 至少有一个还是错的。

## 3. 使能极性 `ENABLE_HIGH` —— `HAND` 模式

`HAND` 模式进入时自动断电、离开时自动恢复，正好用来验证 EN 线是否真的起作用：

- 在 `RUN` 模式拧电机轴：应该**拧不动**（有保持力矩）。
- ENTER 长按切到 `HAND`：应该**能自由拧动**，第一行显示 `drv OFF turnable`。

两种状态表现一样，说明 EN 线没接通、或驱动器 EN 脚悬空默认使能；表现相反（`RUN` 能拧、
`HAND` 拧不动），把 `STEP_MOTOR_BEAM_ENABLE_HIGH` 改成 `0U`。

若切到 `HAND` 后第一行显示 `!! still ON !!`，是驱动层没能真正断电，先查这个再往下做。

实测记录：高电平使能，`1U` 正确。

## 4. 方向极性 `POSITIVE_DIR_HIGH` —— `RUN` 模式

先在机械上定死哪边是正方向（比如"抬右侧"），约定**正速度 = 摆杆向正方向偏**。

`RUN` 模式按 UP（正速度）观察摆杆倒向：一致则现值正确，相反则把
`STEP_MOTOR_BEAM_POSITIVE_DIR_HIGH` 从 `1U` 改成 `0U`。

⚠ 这一项和 #6 必须**分开做、按顺序做**。两个一起翻会互相抵消，测出来的组合是错的但
现象是对的。

实测记录：DIR 高电平即正向，`1U` 正确（`ENCODER_INVERT` 已单独定为 `1U`，两者不是
一起翻的）。

## 5. 编码器每转计数 `ENCODER_COUNTS_PER_REV` —— `HAND` 模式

这是唯一必须实测、猜不出来的值。它错了，`qei` 那一栏的刻度就是错的，闭环也就无从谈起。

1. ENTER 长按切到 `HAND`（自动断电）。
2. ENTER 清零。
3. 手动把轴**正好转 N 整圈**（对准标记慢慢转，别来回找）。转 3~5 圈能摊掉对不准的误差。
4. UP/DOWN 把 `turns` 设成你实际转过的圈数。
5. 读 **`cpr` 栏** —— 那就是 `STEP_MOTOR_ENCODER_COUNTS_PER_REV`。

改完重新烧录，回 `HAND` 再转一圈验证：`cpr` 应该稳定在同一个数，`RUN` 里的 `qei` 转
一圈应读到接近 `360`。

实测记录：断电手转一整圈，`cnt` 变化 **2000**，已填 `2000.0f`。

> MSPM0 的 QEI 2-input 模式对 A/B 各取上升沿，是 **2 倍频**，不是常见的 4 倍频，
> 所以理论值 = 编码器线数 × 2。2000 / 2 = **1000 线**，是常见规格，与原先按 500 线
> 猜的默认值差一倍。测出来接近线数 × 4，说明 SysConfig 的 QEI 模式和驱动里的注释
> 对不上，得回去查。

## 6. 编码器方向 `ENCODER_INVERT` —— `RUN` 模式

#4 和 #5 都定完之后，`RUN` 模式按 UP 跑两秒：

- `est` 与 `cnt` **同号增长** → 保持 `0U`。
- **符号相反**（`est` 涨、`cnt` 跌）→ 改成 `1U`。

实测记录：`est` 为正时 `cnt` 为负，已改成 `1U`。

跑一段后按 ENTER 暂停，读数会停在原地不清零，方便慢慢比对符号和 `slip`；再按 UP/DOWN
可接着往下累积。

改完再跑一次，`slip` 栏（`est - qei`）应该在零附近小幅波动。持续单向发散就是丢步，
直接进 #7。

## 7. 最大步进频率 `MAX_STEP_FREQ_HZ` —— `SWEEP` 模式

`5000` 是抄官方例程的，与本机电压、负载、摆杆惯量都无关，必须自己压出来。

1. 切到 `SWEEP`，UP/DOWN 选转速档（`15 / 30 / 60 / … / 240` deg/s）。
2. ENTER 启动，跑 3~5 秒，看 **`peak` 栏**（本档 `|slip|` 的峰值）。
3. ENTER 停止，UP 升一档，再来。换档会自动清零峰值并重新计数。

判据：`peak` 一直停在很小的值 → 这档能跑；`peak` 随时间持续增大、或听到"咔咔"堵转声
→ **已经丢步**，退回上一档。

取**能稳定跑的最高档的 80%** 作为工作上限（给摆杆动态加速留余量），`f` 栏就是该转速
换算出的步进频率，直接抄回 `STEP_MOTOR_MAX_STEP_FREQ_HZ`。

⚠ 必须**装上摆杆、带真实负载**测。空载能跑到的频率，挂上摆杆通常要打对折。

> 用峰值而不是瞬时 `slip`：丢步是累积的，盯瞬时数容易在两次刷屏之间漏掉。

## 8. `MAX_SPEED_DEG_S` —— 换算

不单独测，由 #7 反推，两者保持一致：

```
MAX_SPEED_DEG_S = MAX_STEP_FREQ_HZ × STEP_ANGLE_DEG / MICROSTEP
```

不一致的后果是限幅在两处各切一刀，实际上限取更严的那个——不会出错，但会让调参时
"改了没反应"。

## 9. 摆杆减速比 `k` —— `SPAN` 模式

驱动层的所有角度都是**电机轴角**，不是摆杆角。中间隔着连杆 / 同步带 / 减速箱：

```
摆杆角 θ = 电机轴角 / k
```

1. 切到 `SPAN`。**按住** UP 或 DOWN 点动（松开即停），把摆杆开到一个明确的机械参考位
   （比如靠住限位块）。
2. ENTER 打 **A** 点。
3. 点动到另一个参考位，ENTER 打 **B** 点。
4. 读 **`d` 栏** —— 两点间的电机轴角（deg）。
5. 用量角器或手机水平仪量摆杆实际转过的角度 `θ`。

```
k = d / θ
```

同步带直连的话 `k` 就是带轮齿数比，有减速箱要再乘减速比——量出来的值应该和机械算出来
的对得上，对不上说明中间有打滑或 #5 还没标准。

> `A`/`B`/`d` 都由编码器计数换算而来，所以 **#5 必须先做完**，否则这三个数的刻度是错的。

## 10. 软限位 `MIN/MAX_POSITION_DEG` —— 换算

现在是 `±100000`，**等于没有限位**——机械没装好时的临时设置，装机后必须改回来，否则
程序跑飞会把摆杆顶到机械死点上。

摆杆物理行程为 `±θ_max`（留 5° 安全余量）：

```
MAX_POSITION_DEG = (θ_max - 5) × k
MIN_POSITION_DEG = -MAX_POSITION_DEG
```

也可以运行时用 `StepMotor_SetPositionLimit()` 覆盖，不必重编译。

> ⚠ 软限位只作用于**开环估计位置** `est`。丢步之后 `est` 和真实角度就脱节了，限位会
> 连带失效。它防的是指令超程，**不能替代物理限位开关**。

## 常见现象对照

| 现象 | 可能原因 |
|---|---|
| 只嗡嗡响不转 | 驱动板线序错（A+/A-/B+/B- 接反），或 `f` 超出电机启动频率 |
| `est` 涨、`cnt` 不动 | 编码器供电 / A、B 线未接，或 QEI 引脚接错 |
| `est` 与 `cnt` 反号 | `ENCODER_INVERT` 需翻转（#6） |
| `slip` 越跑越大 | 丢步，降 `MAX_STEP_FREQ_HZ`（#7）或加大驱动电流 |
| 转速整体差固定倍数 | `MICROSTEP`（#2）或 `STEP_TIMER_CLK_HZ`（#1）不对 |
| `f=0`、`load=0` | 指令速度落进死区，低于 `MIN_STEP_FREQ_HZ` |
| `HAND` 页显示 `!! still ON !!` | EN 极性错或 EN 线未接（#3） |
| `TURN` 走完圈数明显不对 | `MICROSTEP` 不对（#2），这正是该模式要测的 |
